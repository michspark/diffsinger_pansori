# DiffSinger (OpenVPI maintained version)

## README summary

OpenVPI describes this repository as a refactored and enhanced DiffSinger implementation. The README highlights a reorganized codebase, 44.1 kHz output, improved acoustic models and diffusion-sampling acceleration, variance-model controls for pitch, energy, and breathiness, and production-oriented integration with the singing-voice-synthesis community. It links Chinese tutorials, dataset/preprocessing tools, deployment guidance, diffusion and rectified-flow references, HiFi-GAN/NSF vocoder components, RMVPE, and vocal-removal dependencies.

The repository is Apache-2.0 licensed and includes a consent-focused disclaimer against generating a person's voice without permission.
