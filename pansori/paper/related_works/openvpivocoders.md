# DiffSinger community vocoders release page

## README-equivalent summary

The `openvpi/vocoders` repository is a GitHub Pages release page for DiffSinger community vocoders. Its landing-page source (`index.md`, used here because the repository has no `README.md`) documents downloadable waveform vocoders and example audio resources for DiffSinger users. The repository is licensed under AGPL-3.0.

This note records the repository source used by the pansori paper for NSF-HiFiGAN singing-vocoder assets; it is not a research paper.
