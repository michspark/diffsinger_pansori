# SOFA: Singing-Oriented Forced Aligner

## README summary

SOFA is a forced-alignment tool designed specifically for singing voice. Its README claims easier installation, better singing alignment performance, and faster inference than MFA. The documented workflow uses Python 3.8, a trained checkpoint, a phoneme dictionary or custom G2P module, paired `.wav`/transcription segments, and `infer.py`; output can be written as TextGrid, HTK, or `trans` annotations. It also documents matching mode, ONNX inference, confidence scores, and boundary-edit evaluation. The repository is MIT licensed.
